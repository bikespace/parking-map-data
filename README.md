# BikeSpace Project Data

These folders contain data used in the [BikeSpace web app](https://bikespace.ca/). For more information, see the README in each folder.

BikeSpace user submissions can be accessed using the [BikeSpace API](https://api-dev.bikespace.ca/api/v2/docs/).

## Bike Parking Data

`/bicycle_parking` folder, updated daily

Cleaned dataset of bicycle parking locations in the City of Toronto using data sourced from the City of Toronto Open Data portal and OpenStreetMap.

This data is used in the [BikeSpace bicycle parking map](https://bikespace.ca/parking-map).

## Bike Network Data

`/bicycle_network` folder, updated daily

Cleaned version of the [City of Toronto cycling network dataset](https://open.toronto.ca/dataset/cycling-network/).

This data is used in the [BikeSpace bicycle parking map](https://bikespace.ca/parking-map).

## Bike Parking in Apartments

`/apartments` folder, updated daily

Data on bicycle parking in City of Toronto apartment buildings using open data from the RentSafeTO program.
